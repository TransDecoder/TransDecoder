# TransDecoder

> **PyTransDecoder supersedes this Perl TransDecoder.** [PyTransDecoder](https://github.com/TransDecoder/PyTransDecoder) is the Python implementation of the same method, and new users are encouraged to start there. It runs faster (about 2.7 times on our benchmark) and has more features, including homology-assisted start-codon refinement and building your own presets (`build-preset`). Without homology evidence, it gives the same predictions as Perl TransDecoder v7. Perl TransDecoder remains available for existing pipelines.

Visit the project [wiki](https://github.com/TransDecoder/TransDecoder/wiki) for all TransDecoder documentation.
